WHAT CHANGES

MONEY AND STOCK
1. Sell saved as the whole truck — FIXED
   A ticket with no weigh-in can no longer be finished. Staff see:
   "This ticket has no weigh-in weight. Fix it with Edit Ticket first,
   then finish."

2. Daily Book profit for "All stations" — FIXED
   Each station's stock and cost are now worked out on their own, then
   added up — the same way the Income Statement does it. The two now
   agree. Single-station views are unchanged.

3. Record Payment, paying too much — FIXED
   Typing more than is owed now shows a red message straight away and
   the Record Payment button is greyed out. The false "someone recorded
   a payment" message only appears when someone really did.

STAFF CAN'T WORK
4. "Wrong password" with no internet — FIXED
   The message now says there is no internet, not that the password is
   wrong. The password rule itself is unchanged: no internet, no save.

WRONG OR MISSING INFORMATION
5. Daily Book "Year total" — FIXED. Shows the whole year, not one month.
6. Printed expense sheet — FIXED. Uses only the printed station's
   "nothing spent" marks. For all stations, a day counts as "nothing
   spent" only when every station marked it.
7. Expense print at "Year" — FIXED. No longer empty.
8. ×N on the Receipt button — FIXED. Goes up as soon as you print.

SMALL

    void and correct payment. "Was: … on …" is now in Khmer too.
10. "Check the two weights." — now in Khmer too.
