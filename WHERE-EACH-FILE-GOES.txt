1. SETTING A STATION'S STOCK - ANY FIGURE, ANY OF THE LAST 7 DAYS
-----------------------------------------------------------------
  "not everything sotck should be reset to 0, it should be able to adjust
   as well for stock left overnight"
  "i notice it doesnt have the option to set a date for a reset. like
   yesterday"

  Every station on the HQ Dashboard now has a control:

    a NEGATIVE station  ->  green "Settle N kg"  (one tap, it is drift)
                            or gold "Fix N kg to 0" (reason + password)
    every other station ->  grey "Set stock"

  "Set stock" opens the SAME Adjust Stock screen that Stock Inventory has
  always used - not a second one, so three screens cannot disagree about
  the rules or the password step. There you can:

    - type the real amount (3,000 kg left in the shed) or take it off the scale
    - or press "Reset to 0" if the shed really is empty
    - choose WHICH DAY it counts against: Today / Yesterday / pick a date,
      up to 7 days back, in Cambodia's calendar
    - give a reason, and if it is a loss it asks the price and shows the value

  The date was already supported by the database all along - nothing was
  passing one. Now all three screens that adjust stock do.

  Also: looking at "Yesterday" on the Dashboard used to hide every button on
  every row, so a day that needed correcting could not be corrected. That
  condition is gone; the screen picks its own day now.
